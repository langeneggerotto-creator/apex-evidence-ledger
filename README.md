# apex-evidence-ledger

Authoritative evidence and traceability layer for APEX claims, readiness, decisions, forks, exceptions, promotion gates, and Core OS compliance.

## Current Core OS policy evidence contract

- `schemas/core-os-policy-evidence-record-v0.1.schema.json`

This schema defines the portable record OCODE Law Guardian v0.2 must produce. It covers source-registry provenance, applicable readiness dimensions, implementation status, evidence references, weakest barriers, gap responses, route-fit information, ownership and maintenance status, anti-paralysis results, unresolved gaps, exceptions, human approval, promotion decisions, and reassessment triggers.

Truth boundary: the schema is implemented. Evidence Ledger storage, validators, indexing, user interface, and operational-compliance enforcement remain under development.
